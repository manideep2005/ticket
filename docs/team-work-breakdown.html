2. Google Cloud Functions & Infrastructure Architecture

[Google Cloud Platform Stack]
├── Google Cloud Run (2nd Gen Container): Hosts Express API & static frontend on Port 8080. Zero idle scaling.
├── HTTP Cloud Function (apiRouter): Exposes REST endpoints; validates Google OAuth 2.0 cryptographic JWT tokens.
├── Google Cloud Pub/Sub ('ticket-created' Topic): Decouples ticket intake from asynchronous automated routing.
├── Event-Driven Background Cloud Function: Pulls from Pub/Sub, executes Caseload Balancing, sets SLA deadlines.
├── Google Cloud Firestore (Native Mode): NoSQL durable document store (collections: tickets, messages, users).
└── Google Identity Services (OIDC): Google OAuth 2.0 Web Client for cryptographically signed user sessions.

3. Detailed Role Permissions & Security Matrix

Customer Role User Role

External or internal client submitting service requests.

  • Ticket Submission: Can create new tickets with auto-categorization.
  • Data Privacy Isolation: Can ONLY view and search their own tickets (scoped by customerId).
  • Conversation Thread: Can view messages and reply to support agents.
  • Resolution: Can mark their own resolved issues as closed.
  • Restricted: Cannot access agent queues, admin routing rules, or organizational KPI reports.

Support Agent Role Staff Role

Engineering & Support specialists handling triage queues.

  • Full Queue Visibility: Can view tickets across all teams and categories.
  • Lifecycle Control: Can advance tickets: Assigned ➔ InProgress ➔ WaitingForCustomer ➔ Resolved.
  • SLA Tracking: Real-time alerts on tickets approaching or breaching resolution targets.
  • 1-Click AI Responses: Insert automated troubleshooting templates based on triage tags.
  • CSV Data Export: Can export full ticket archives for audit purposes.

Admin Role Executive Role

System administrators and platform engineering leads.

  • Routing Rule Governance: Configure category-to-team assignments and priority floors.
  • Executive Analytics: Access organizational SLA Compliance Rates, Mean Resolution Times, and volume charts.
  • Team Caseload Audit: Monitor workload balance across engineering departments.
  • Full Override Privileges: Reassign agents, modify ticket states, and manage system parameters.
